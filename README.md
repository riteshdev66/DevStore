# DevStore — E-commerce Landing Page

DevStore is a laptop e-commerce landing page built with HTML and CSS. The project focuses on creating a clean, modern shopping interface with product cards, promotional sections, and a responsive layout.

## 🔗 Live Demo

[View DevStore Live](https://riteshdev66.github.io/DevStore/)

## 📸 About the Project

DevStore is a front-end practice project designed to improve my understanding of HTML, CSS, page layouts, and responsive web design.

## ✨ Features

- Responsive navigation bar
- Hero section with a promotional message
- Features section highlighting shopping benefits
- Laptop product cards with prices
- Promotional banner
- Footer with navigation links
- Responsive layouts for different screen sizes

## 🛠️ Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Media Queries
- Google Fonts
- Remix Icon

## 🚀 Run Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/riteshdev66/DevStore.git
   ```

2. Open the project folder in VS Code.

3. Open `index.html` in your browser, or use the Live Server extension.
